Ski pistes and lifts for the Trackstar slopes maps, one file per 0.1° tile
(`{floor(lat*10)}_{floor(lon*10)}.json`).

Built from OpenSkiMap's exports (https://openskimap.org), which are derived from OpenStreetMap.
© OpenStreetMap contributors. This data is available under the Open Database License (ODbL):
https://opendatacommons.org/licenses/odbl/1-0/

Lines are simplified to ~4 m and coordinates rounded to 5 decimals.
